# Release status

This is a local publication candidate. It has not been pushed, uploaded or
assigned a public repository URL or DOI.

The package was assembled from an explicit allowlist of the manuscript's
standalone research modules, synthetic JSON instances and archived outputs.
Industrial repository files, binaries, credentials, local configuration and
Git history are excluded. The accompanying local review records dependency,
content and source-overlap checks; those checks are evidence about the selected
files, not a legal determination of ownership.

Before public publication:

1. Confirm the research-code and synthetic-data licences.
2. Create the separate public repository using these files, excluding `outputs/`,
   `.venv/` and compiled libraries. No industrial repository should be published.
3. Archive a tagged version if a persistent identifier is desired.
4. Insert the verified public URL or identifier into the manuscript, cover letter,
   title page and response. Their current statements describe a prepared package.

The author controls Git operations and publication. The reference solver and
archived campaign are preserved together so the released code describes the
actual reported experiment.
